# 서버 작업 요청: 조직 문서함(RAG) 검색 스코어링/랭킹 품질 문제

> **상태: 미해결 (2026-07-14 실측).** `/api/v1/knowledge/search` 의 **인증/엔드포인트는 정상**
> (별도 문서 `SERVER_TASK_KNOWLEDGE_SEARCH.md` 로 해결됨). 이 문서는 그 다음 단계 — **검색 결과의
> 스코어링과 랭킹이 질의를 반영하지 못하는** 문제입니다.

## 한 줄 요약
**서로 다른 11개 질의가 전부 동일한 문서를 1위(score 1.00)로 반환합니다.** 스코어가 실제 유사도를
반영하지 못하고(대부분 1.00으로 포화), 특정 문서 하나가 모든 질의를 지배합니다. 결과적으로 CLI
에이전트가 관련 문서를 변별하지 못해 **같은 질문을 여러 각도로 10~20회 재검색**하게 됩니다.

## 실측 근거 (moai-code CLI → `/api/v1/knowledge/search`, `scope:all`)

에이전트에게 "조직 문서함에서 AI 정책 문서 검색·요약해 문서 만들어줘"를 시키자, 모델이 아래 11개의
**서로 다른, 점점 구체화되는** 질의를 순차로 보냈습니다. 각 질의의 **1위 결과가 전부 동일**합니다:

11번처럼 **"행정명령 14110호 제4조 레드팀 NIST 이중용도 기반모델"** 이라는 매우 구체적인 질의에도
1위는 여전히 `AI 거버넌스 핵심 동향과 정책 시사점` (1.00). 정작 그 주제의 문서(`Artificial
Intelligence Law Issue Brief`)가 있는데도 뒤로 밀립니다.

### 스코어 분포 (위 11개 질의의 전체 결과 합산)
```
score 1.00 : ██████████████████████ 22건   ← 압도적. 유사도 정규화가 1.0 에 포화
score 0.9x :  ████                    5건
score 0.8x :  ██████                  6건
score 0.7x :  █████                   5건
score 0.42 :  █                       1건
```
top-1(그리고 흔히 top-2)이 항상 정확히 `1.00`. 스코어가 **변별력이 없습니다.**

## 증상 → 영향
- 능력 있는 모델(gpt-5.6 계열)은 결과가 변별되지 않으니 **질의를 11~20회 바꿔가며 재검색** →
  RAG 호출 낭비 + 지연 + (턴 예산 소진 시) 작업 미완. CLI 는 기본 MaxTurns 를 25로 올려 완주는
  시켰지만, 이는 증상 완화일 뿐 근본 원인은 서버 검색 품질입니다.
- 약한 모델은 그냥 첫 결과를 받아쓰므로 **한 문서만 반복 인용**하는 편향된 요약이 나옵니다.

## 원인 후보 (RAG 팀 확인 요망)
1. **스코어 정규화가 1.0 에 포화** — 코사인 유사도/리랭커 점수를 min-max 등으로 정규화하며 top-1 이
   항상 1.0 이 되는지. 원 점수(정규화 전)를 로깅해 확인.
2. **특정 문서의 임베딩 지배** — `AI 거버넌스 핵심 동향과 정책 시사점` 문서가 중복 청크/과대 길이/
   특이 임베딩으로 모든 질의에 최상위로 매칭되는지(임베딩 중복·정규화 문제).
3. **하이브리드 검색 가중치** — FTS + 벡터 결합 시 한쪽이 상수 점수를 뱉어 랭킹을 지배하는지
   (`performHybridSearch` 의 결합 로직).
4. **쿼리 확장 붕괴** — `queryExpansion.allQueries` 가 모든 입력을 유사한 확장으로 수렴시키는지.

## 기대치 (what good looks like)
- [ ] 서로 다른 질의는 서로 다른 top 문서를 반환(질의 특이성이 랭킹에 반영).
- [ ] 스코어가 0~1 구간에 **분포**(전부 1.00 이 아니라 실제 유사도 차이 반영).
- [ ] "행정명령 14110 제4조" 같은 구체 질의는 해당 주제 문서를 상위로.
